# Diary reference library

Public diary by Блашкевич Надежда Никифровна, from the Minlos family archive. This folder contains data, not instructions to load into a model.

- [sources/](sources/) — original photographs; [source manifest](source-manifest.json).
- [crops/](crops/) and [contact sheets](contact-sheets/) — extracted examples.
- [index.json](index.json) / [index.csv](index.csv) — labels, source coordinates and provenance.
- [transcripts/](transcripts/) — page readings; [handwriting profile](handwriting-profile.md).
- [ambiguities](ambiguities.csv) and [error log](error-log.csv) — unresolved or corrected readings.

Paths stored in data manifests are relative to this folder. Confirmed and provisional labels remain distinct. Photographs, text and annotations use [CC BY 4.0](LICENSE-DATA.md).
