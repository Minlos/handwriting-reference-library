# Extract handwriting references across a collection

Use all permitted scans and the available provisional transcripts. Make a provisional first reading of every image when transcripts are absent or incomplete. Track each image's coverage, unresolved spans and likely writer. Envelopes, postmarks and repeated names can supply clues. Preserve image-supported distinctions between writers.

1. Search the whole relevant collection for clear instances of a difficult word, letter shape or join. Compare recurring wording and visual forms. Use requested and available OCR tools to supply additional candidate readings; keep their independent outputs. Select references because they address an uncertainty, without a fixed limit on how many source pages can contribute.
2. Extract complete examples from original pixels when image tools are available. Keep page, bounds, rotation and proposed label with each crop. Inspect actual crops before using them. Re-crop clipped words and discard blank or unrelated regions. Visual-only hosts may compare regions directly.
3. Compare uncertain spans with the examples and OCR candidates. Revisit initially clear readings when collection evidence conflicts with them. Revise only where the target strokes support the change, preserve unusual wording, and record the previous reading, new proposal and source evidence.
4. Reread every supplied page with the accumulated evidence. Refresh provisional examples after checking their source images, and repeat the comparison and rereading cycle while supported changes occur. Stop when a full pass yields none, or a stated time/cost limit or access blocker is reached. Record coverage and unresolved text at the stopping point.

Labels inferred by a model remain provisional until human confirmation. Keep ambiguous readings and competing alternatives visible. Context and agreement between tools do not verify a label. Store crops temporarily unless the user requests a saved library.

For a restricted evaluation, follow its permitted-page rules and keep corrected target text with the scorer. Treat whole-collection rereading as its own workflow. Keep the initial outputs and all later passes so improvements and regressions can be checked.
