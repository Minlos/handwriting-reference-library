# Popov letters: raw-only extraction tests

raw-sources.json lists 27 source sides from 14 letters, excluding all sides of corrected test letters L01, L09 and L13. Retrieve only these permitted public URLs and verify hashes before use; no API call is implied. There are no verified Popov readings in this extractor input. Record transforms if images are resized before cropping.

Compare the same neutral extraction request with and without the extraction skill, in fresh contexts. Freeze both resulting packets. Use the same fixed reading model and reading instructions to compare their effect on the three held-out letter excerpts. Do not repair one packet after seeing target scores. Without source gold, output quality on raw letter labels needs independent review; source hashes and valid bounds alone do not establish correct readings.

Diaries are tested separately with raw scans and with verified source readings. The three corrected Popov letters are evaluator material only. This collection has no assigned reuse license.
