# Optional test material

These public diary examples are known diagnostics, not evidence of general improvement and not the new Popov-letter benchmark. The `input/` subfolder contains the actual images; `inputs.json` records their source files. The skill works without this folder.

Give a fresh tested model only `task.txt`, the actual `input/` images and, in the skill condition, the parent `SKILL.md`. Keep this README, `evaluator/`, source transcripts and the coordinator conversation out of its input. A no-skill condition gets the same task and images. Disable accidental inherited skill/reference access while preserving normal security controls.

The evaluator may inspect answers after predictions are frozen. Extraction checks source bounds, complete word boundaries, source coverage, label errors and truthful provisional status; selecting different valid examples is not automatically a failure. Reading checks character errors, omissions and preservation of unusual wording. The supplied labels do not certify each individual glyph boundary. No model tests of these revised standalone skills have been run.

Images and diary annotations: Блашкевич Надежда Никифровна, Minlos family archive, CC BY 4.0. See `LICENSE-DATA.md`. This data license does not assign a license to skill instructions. The separate Popov-letter pilot is described in the repository evaluation plan; private letter scans are not included here.
