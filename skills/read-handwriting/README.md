# Read handwriting

Read [SKILL.md](SKILL.md) for the complete instructions. Copy that plain Markdown file into any suitable LLM host. This skill does not require the rest of the repository or another skill.

Optional [test material](test-material/README.md) is kept separately: `input/` contains actual images, `task.txt` contains the exercise, and `evaluator/` contains answers that must stay out of model input. These are known diary diagnostics; the standalone skill now has small pilot results, with no general improvement established.
