# Test final verification and collection rereading on new letters

For the newly separated extraction and reading skills, use the [Popov-letter pilot](LETTERS-TWO-SKILLS.md). The existing four-condition handoff below remains a frozen diary experiment, not the standalone-skills protocol.

Finish human correction of complete letters before running new paid comparisons. Keep unresolved words excluded by an explicit shared mask. Freeze both the human reference and model outputs before examining scores. Do not call corrected calibration pages an untouched test set.

1. Run the known behavioral cases as diagnostics. Inspect whether plausible word substitutions, altered line openings and lost uncertainty survive the final image check. Record failures as well as improvements.
2. Reserve complete letters from each writer for evaluation. Other letters by that writer may supply references; target corrections, overlapping crops and target-derived profiles must not enter the blind request. Do not mix the writers' examples.
3. Reuse the existing four-condition handoff: neither skill nor examples, skill only, examples only, both. Freeze the exact revised skill, prompts, image hashes, model version and settings. Repeat trials to show variation; do not announce a gain from a single lucky reading. Historical runs keep their original skill snapshots.
4. Separately compare the initial reading with a final image-verification pass and with a whole-collection rereading cycle. Save all versions. Allow unlabeled target images in an ordinary collection cycle, but describe it as such; it is different from an independent held-out letter test.

Report total character errors divided by total scored reference characters, omissions, plausible substitutions, altered names/numbers, unresolved spans and review time. Check improvements against regressions: fewer errors overall can still hide a badly changed sentence. Report the contribution of instructions separately from the contribution of examples. Do not promise a target accuracy before measuring it.

No new paid model calls are authorized by this plan itself. The current instruction is to prepare and correct text first; experiments follow after the user chooses to resume them and sets a budget.
